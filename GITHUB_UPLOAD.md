# Загрузить PulseStream как отдельный GitHub-репозиторий

Эта папка — полностью самостоятельный проект. Для сборки не нужны файлы из соседних папок.

1. Создай пустой репозиторий `pulsestream` в своём GitHub.
2. Выбери **uploading an existing file** или **Add file → Upload files**.
3. Загружай содержимое именно этой папки: `pom.xml`, `README.md`, `src/`, `tools/`, `docs/`, `benchmarks/`, `mvnw`, `mvnw.cmd`, `dev.ps1`, `.mvn/`, `.github/`, `.vscode/`, `.gitignore` и этот файл. `pom.xml` должен оказаться в корне репозитория.
4. Не загружай `target/`, `data/`, `__pycache__/` и личные файлы. В готовом ZIP этих файлов уже нет. Распакуй ZIP перед загрузкой: загрузка самого ZIP не создаёт дерево исходников.
5. Проверь наличие скрытых папок `.mvn` и `.github` после загрузки. Через GitHub Desktop они добавляются обычным коммитом; в браузере при необходимости создай отсутствующие файлы через **Add file → Create new file**, указав полный путь.
6. После коммита проверь вкладку **Actions**: workflow запускает сборку и smoke-тесты.

Альтернатива: открой эту папку через GitHub Desktop → **Add existing repository** / **Create a repository here**, затем опубликуй отдельный репозиторий. Выбирай именно эту папку, а не внешнюю папку портфолио.

Перед загрузкой можно проверить проект отдельно: `./dev.ps1 build`, затем `./dev.ps1 smoke`. Локальные инструменты и данные исключены из Git через `.gitignore`.
